<h3>🧑‍💻 About Me</h3>

<p>
I'm an <b>Information Security Engineering</b> student at Universidad de Manizales (Colombia), recognized with academic excellence scholarships. My focus is offensive security and secure infrastructure: I hunt bugs on <b>HackerOne</b>, compete in <b>CTFs</b>, and build self-hosted labs to understand how real systems are attacked and defended.
</p>
<p>
I'm currently growing into <b>DevSecOps</b>: infrastructure as code, hardening with Ansible, secure CI/CD pipelines and zero-trust exposure of services. Open to <b>junior / trainee</b> roles, remote or on-site during the day.
</p>
